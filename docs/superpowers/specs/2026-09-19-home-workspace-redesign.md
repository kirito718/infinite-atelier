# Infinite Atelier 工作区入口重构设计规格

## 目标

将当前偏宣传页的首页改造成可直接开始工作的“工作区入口”。用户打开 Infinite Atelier 后，应优先看到最近画布、继续编辑和新建入口，而不是阅读 Hero 文案或滚动寻找项目。

本规格基于 Pencil 设计稿确认，设计稿为 [`docs/design/infinite-atelier-home-workspace-mcp.pen`](../../design/infinite-atelier-home-workspace-mcp.pen)。

## 已确认的方向

- 保留根路由 `/`，但将其内容改造成 Workspace Entry，不再作为营销 Landing Page。
- 入口首屏以“继续创作”为主动作，优先展示最近打开的画布。
- 提供三条快速开始路径：空白画布、导入参考、提示词起步。
- 最近画布使用项目卡片展示标题、更新时间、节点/连接数量和继续编辑状态。
- 新建画布使用应用内状态面板，不触发浏览器原生弹窗。
- 菜单和主要操作尽量使用中文；品牌名 Infinite Atelier 和项目专有名词保留原样。
- Prompt Library 不再占据首页首屏，后续归入资产/画布工作流；本次不删除已有能力。

## 信息架构

桌面端使用左侧工作区导航，主区域承载当前入口内容：

- 工作区
  - 画布
  - 导演
  - 资产
- 系统
  - 配置

主区域顺序固定为：

1. 页面标题与搜索、导入操作
2. 继续创作：最近打开项目 + 快速开始
3. 最近画布列表

现有 `/canvas`、`/director`、`/assets`、`/config` 路由保持不变。画布详情页继续隐藏全局导航，避免干扰无限画布操作。

## 交互契约

### 继续创作

- 最近打开项目展示为主卡片；点击卡片或“打开项目”进入 `/canvas/:id`。
- 项目不存在时，主卡片区域退化为空状态，并将“新建画布”作为唯一主要动作。
- 项目统计来自现有 `CanvasProject` 的 `nodes` 和 `connections`，更新时间沿用当前本地化格式。

### 快速开始

- “空白画布”：调用现有 `createProject`，创建后立即进入新项目。
- “导入参考”：复用现有画布包导入逻辑，失败时显示应用内错误反馈并保留当前页面状态。
- “提示词起步”：进入现有提示词/资产工作流；若当前实现没有独立入口，先复用现有 Prompt Library 数据和保存能力，不新建第二套数据源。

### 新建画布面板

- 面板提供关闭/取消操作，焦点和滚动保持在应用内。
- 三个选项均使用清晰的中文标题和辅助描述。
- 不使用 `alert`、`confirm`、`prompt` 或自动打开外部窗口。
- 创建动作期间保留按钮尺寸并显示进行中状态，避免重复创建。

## 视觉与本地化

- 延续现有 Infinite Atelier 的中性色、赤陶色强调色和 Ant Design/Tailwind 主题，不引入新的字体资产或品牌渐变。
- 左侧导航提供当前路由的明确选中态，图标仅作为文字的辅助。
- 桌面端使用中等密度；卡片只在承载独立操作或项目信息时使用，避免把所有内容包成卡片。
- 所有菜单、按钮、状态和空状态提供 `zh-CN` / `en-US` 对应文案，意义保持一致。
- 本次新增或替换的中文键包括：工作区、画布、导演、资产、系统、配置、继续创作、快速开始、最近画布、新建画布、导入参考、提示词起步等。

## 响应式行为

- 桌面端：左侧导航固定，主区域可滚动；最近画布按三列展示。
- 窄屏端：左侧导航收起为现有移动导航抽屉；主区域单列显示；最近画布改为单列堆叠。
- 新建画布面板在窄屏端变为接近全宽的底部/居中面板，选项保持纵向排列。
- 不新增横向滚动容器；搜索、导入和主要按钮在窄屏端保持可触达。

## 实现边界

本次包含：

- 首页入口组件重构。
- 全局导航从当前首页兼容结构调整为工作区导航视觉。
- 中文菜单与相关 i18n 文案。
- 最近项目、空状态、加载状态和新建面板状态。
- 桌面/窄屏布局与键盘可访问性。

本次不包含：

- 画布编辑器内部工具重构。
- Prompt Library 数据模型重构或删除。
- 账户、持久化、模型配置和生成服务改动。
- 新增服务端接口。

## 验收标准

- 进入 `/` 后，首屏无需滚动即可看到继续创作和新建入口。
- 菜单和主要操作在中文环境下不再使用英文功能名。
- 最近项目、无项目、加载和导入失败状态均有明确反馈。
- 新建画布不会重复创建项目，创建后能进入正确的 `/canvas/:id`。
- `/canvas` 等现有路由仍可访问，画布详情页不被新的全局导航覆盖。
- 桌面和窄屏布局均无裁切、重叠或不可操作控件。
- 现有测试、类型检查、构建和浏览器流程通过。
